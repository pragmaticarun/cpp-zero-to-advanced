    Lesson 7.2: Class templates, specialization, and CTAD¶

    C++20 · about 12 minutes

    Why this matters¶

    std::vector<int> and std::vector<std::string> are two different classes generated from one template. In this lesson we'll write our own small class template — a fixed-size statistics window for sensor readings — and learn how to customize it for particular types.

    A class template¶

    template <typename T, std::size_t N>
class Window { std::array<T, N> data_{}; ... };

Window<float, 4> w;     // a class generated for (float, 4)

    Member functions are only instantiated if they're used — so a Window<std::string, 3> compiles fine as long as you don't call mean() on it.

    Specialization¶

    • Full specialization gives a completely different implementation for one exact set of arguments: template <> struct TypeName<int> { ... };
    • Partial specialization (classes only, not functions) customizes for a pattern: template <typename T> struct TypeName<T*> { ... };

    The standard library uses this everywhere (e.g. std::hash<T> specializations, std::vector<bool>, which is a famous cautionary tale: it packs bits and so its operator[] doesn't return a real bool&).

    CTAD (C++17)¶

    std::pair p{1, 2.5};       // pair<int, double> — no need to spell out the arguments
std::vector v{1, 2, 3};    // vector<int>

    The compiler deduces class template arguments from constructor arguments. When that doesn't work the way you want, a deduction guide tells it how.

    examples/week07/lesson02.cpp
    #include <array>
#include <cstddef>
#include <iostream>
#include <string>
#include <vector>

template <typename T, std::size_t N>
class Window {                                    // fixed-size rolling window
public:
    void push(T v) { data_[next_ % N] = v; ++next_; }
    std::size_t size() const { return next_ < N ? next_ : N; }
    T mean() const {                              // only instantiated if used
        T total{};
        for (std::size_t i = 0; i < size(); ++i) total += data_[i];
        return total / static_cast<T>(size());
    }
private:
    std::array<T, N> data_{};
    std::size_t next_ = 0;
};

template <typename T> struct TypeName { static std::string get() { return "unknown"; } };
template <> struct TypeName<int> { static std::string get() { return "int"; } };          // full
template <> struct TypeName<float> { static std::string get() { return "float"; } };
template <typename T> struct TypeName<T*> {                                              // partial
    static std::string get() { return "pointer to " + TypeName<T>::get(); }
};

template <typename T>
struct Tagged {
    T value;
    std::string tag;
};
Tagged(const char*, const char*) -> Tagged<std::string>;   // deduction guide

template <typename T> constexpr T pi = T(3.14159265358979323846L);   // variable template
template <typename T> using Grid = std::vector<std::vector<T>>;      // alias template

int main() {
    Window<float, 4> w;
    for (float x : {1.0f, 2.0f, 3.0f, 4.0f, 10.0f}) w.push(x);
    std::cout << "mean of last 4: " << w.mean() << '\n';

    Window<std::string, 2> names;                 // fine: mean() never instantiated
    names.push("a");
    std::cout << "names.size()=" << names.size() << '\n';

    std::cout << TypeName<int>::get() << ", " << TypeName<float**>::get() << ", "
              << TypeName<double>::get() << '\n';

    std::pair p{1, 2.5};                          // CTAD: pair<int, double>
    Tagged t{"hello", "greeting"};                // guide: Tagged<std::string>
    std::cout << p.second << ' ' << t.value.size() << '\n';
    std::cout << pi<float> << ' ' << pi<double> << '\n';
    Grid<int> g(2, std::vector<int>(3, 7));
    std::cout << g.size() << 'x' << g[0].size() << '\n';
}

    Output:

    mean of last 4: 4.75
names.size()=1
int, pointer to pointer to float, unknown
2.5 5
3.14159 3.14159
2x3

    Alias and variable templates¶

    template <typename T> using Buffer = std::vector<T, MyAllocator<T>>;
template <typename T> constexpr T pi = T(3.14159265358979323846L);

    Pitfall: CTAD with braces and copies

    std::vector v{std::vector{1,2}}; is vector<int> (copy), not vector<vector<int>>. CTAD prefers the copy deduction candidate. When in doubt, spell out the type.

    Key takeaways¶

    Key takeaways

    • Class templates generate a class per argument set; unused members aren't instantiated.
    • Full specialization replaces the template for exact arguments; partial specialization matches patterns (classes only).
    • CTAD deduces class template arguments from constructors; deduction guides steer it.
    • Alias templates and variable templates shorten generic code.

    Quiz¶

    Q1. Why does Window<std::string, 2> compile even though mean() divides by static_cast<std::string>(size())?

    Show answer

    Member functions of class templates are only instantiated when used; mean() is never called.

    Q2. Can you partially specialize a function template?

    Show answer

    No. Only class (and variable) templates can be partially specialized; for functions use overloading or if constexpr.

    Q3. What type does std::pair p{1, 2.5}; have?

    Show answer

    std::pair<int, double>, via CTAD.
