    Lesson 12.4: Text: std::format, std::print, iostreams, charconv, and Unicode¶

    C++23 · about 13 minutes

    Why this matters¶

    Printing a table of meter readings with aligned columns used to mean either printf (fast, type-unsafe) or iostreams (type-safe, verbose, slow, stateful). C++20's std::format and C++23's std::print give you Python-style formatting that's type-safe, checked at compile time, and fast. We'll also cover the fastest number parsing in the library (from_chars) and the state of Unicode.

    std::format and std::print¶

    std::println("{:<10} {:>8.2f} dB", name, level);    // left-align 10, right-align 8 with 2 decimals

    Format spec mini-language: {index:fill align sign # 0 width .precision type}. Examples: {:08.3f}, {:#x}, {:^20}, {:+}. The format string is checked at compile time: a mismatch like {:d} with a string is a compile error. For runtime format strings use std::vformat / std::runtime_format (C++26).

    C++23 formats ranges too: std::println("{}", vec) prints [1, 2, 3].

    Custom types¶

    Specialize std::formatter<T>: implement parse (or inherit from an existing formatter) and format.

    examples/week12/lesson04.cpp
    #include <charconv>
#include <format>
#include <iomanip>
#include <iostream>
#include <print>
#include <ranges>
#include <sstream>
#include <string>
#include <string_view>
#include <system_error>
#include <vector>

struct Level { double db; };

template <>
struct std::formatter<Level> : std::formatter<double> {        // reuse double's spec parsing
    auto format(const Level& l, std::format_context& ctx) const {
        auto out = std::formatter<double>::format(l.db, ctx);
        return std::format_to(out, " dB");
    }
};

int main() {
    std::println("{:<8}|{:>8}|{:^8}|", "left", "right", "mid");
    std::println("{:08.3f} {:+d} {:#x} {:#b} {:e}", 3.14159, 42, 255, 5, 12345.678);
    std::println("{1} before {0}", "world", "hello");
    std::println("{:>10.1f}", Level{-3.25});
    std::vector<int> v{1, 2, 3};
    std::println("ranges: {}", v);  // vector<string> needs GCC 15+
    std::string s = std::format("{}-{:03}", "take", 7);
    std::cout << s << '\n';

    std::cout << std::hex << 255 << ' ' << 16 << std::dec << ' ' << 16 << '\n';   // hex was sticky
    std::cout << std::fixed << std::setprecision(2) << 2.0 / 3 << '\n';
    std::cout.unsetf(std::ios::floatfield);

    std::istringstream in{"48000 2 stereo"};
    int rate = 0, ch = 0; std::string mode;
    in >> rate >> ch >> mode;
    std::cout << rate << '/' << ch << '/' << mode << '\n';

    std::string_view text = "1234abc";
    int value = 0;
    auto [ptr, ec] = std::from_chars(text.data(), text.data() + text.size(), value);
    std::cout << "parsed " << value << ", stopped at '" << ptr << "', ok=" << (ec == std::errc{}) << '\n';
    char buf[32];
    auto res = std::to_chars(buf, buf + sizeof buf, 0.1 + 0.2);       // shortest round-trip repr
    std::cout << "to_chars(0.1+0.2) = " << std::string_view(buf, static_cast<std::size_t>(res.ptr - buf)) << '\n';

    std::u8string_view word = u8"caf\u00e9";
    std::cout << "u8\"cafe-acute\" has " << word.size() << " bytes for 4 characters\n";
}

    left    |   right|  mid   |
0003.142 +42 0xff 0b101 1.234568e+04
hello before world
      -3.2 dB
ranges: [1, 2, 3]
take-007
ff 10 16
0.67
48000/2/stereo
parsed 1234, stopped at 'abc', ok=1
to_chars(0.1+0.2) = 0.30000000000000004
u8"cafe-acute" has 5 bytes for 4 characters

    iostreams: still everywhere¶

    You'll still use std::cout, std::ifstream and std::stringstream. Know their pitfalls: manipulators like std::hex and std::setprecision are sticky (they stay set), std::endl flushes (slow in loops — use '\n'), and std::ios::sync_with_stdio(false) speeds up console I/O when you don't mix with C stdio.

    from_chars / to_chars¶

    Locale-independent, non-allocating, non-throwing, and the fastest conversions available. Always check the returned ec and the end pointer.

    Unicode: the honest version¶

    std::string holds bytes; it doesn't know about characters. u8"..." literals are char8_t (C++20), which doesn't convert implicitly to char. size() counts bytes, not characters. For real text processing (normalization, case folding, grapheme clusters) use a library such as ICU. std::print writes UTF-8 correctly to Unicode-capable terminals, which iostreams on Windows historically did not.

    Key takeaways¶

    Key takeaways

    • std::format/std::println give type-safe, compile-time-checked, Python-style formatting.
    • Specialize std::formatter<T> (often by inheriting an existing one) for your types.
    • iostream manipulators are sticky; prefer '\n' over std::endl in loops.
    • from_chars/to_chars are the fastest, locale-free conversions; std::string is bytes, not characters.

    Quiz¶

    Q1. What happens if you write std::format("{:d}", std::string{"x"})?

    Show answer

    A compile-time error: the format string is checked against the argument types.

    Q2. Why can std::endl make output slow?

    Show answer

    It flushes the stream every time; in a loop that defeats buffering.

    Q3. How many bytes does u8"é" (one character, U+00E9) use, excluding the terminator?

    Show answer

    Two bytes in UTF-8.
