# Sources & further reading

## References
- [cppreference.com](https://en.cppreference.com) — the community reference for the language and library. Every feature in this course can be looked up here.
- [C++ Core Guidelines](https://isocpp.github.io/CppCoreGuidelines/CppCoreGuidelines) — Bjarne Stroustrup and Herb Sutter (eds.).
- [The C++ standard drafts](https://eel.is/c++draft/) — the working draft, browsable.
- [isocpp.org](https://isocpp.org) — news, FAQ, and links.
- [Compiler Explorer](https://godbolt.org) — Matt Godbolt.

## Books
- *A Tour of C++* (3rd ed., C++20) — Bjarne Stroustrup.
- *Programming: Principles and Practice Using C++* (3rd ed.) — Bjarne Stroustrup.
- *Effective Modern C++* — Scott Meyers (C++11/14; still the best explanation of move semantics, `auto` and forwarding).
- *C++ Concurrency in Action* (2nd ed.) — Anthony Williams.
- *C++ Templates: The Complete Guide* (2nd ed.) — David Vandevoorde, Nicolai Josuttis, Douglas Gregor.
- *C++17 — The Complete Guide* and *C++20 — The Complete Guide* — Nicolai Josuttis.
- *Embracing Modern C++ Safely* — John Lakos, Vittorio Romeo, Rostislav Khlebnikov, Alisdair Meredith.
- *Real-Time C++* — Christopher Kormanyos (embedded).

## Videos and talks
- [C++ Weekly with Jason Turner](https://www.youtube.com/@cppweekly) — short weekly episodes.
- [CppCon on YouTube](https://www.youtube.com/@CppCon) — including the *Back to Basics* track, which pairs very well with this course.
- Herb Sutter, *"Back to the Basics! Essentials of Modern C++ Style"* (CppCon 2014).
- Chandler Carruth, *"Efficiency with Algorithms, Performance with Data Structures"* (CppCon 2014).
- Mike Acton, *"Data-Oriented Design and C++"* (CppCon 2014).
- Sean Parent, *"Inheritance Is The Base Class of Evil"* (GoingNative 2013) — type erasure.
- Herb Sutter, *"atomic<> Weapons"* (C++ and Beyond 2012) — the memory model.
- Fedor Pikus, *"C++ atomics, from basic to advanced"* (CppCon 2017).
- Gor Nishanov, *"C++ Coroutines: Under the covers"* (CppCon 2016).
- Timur Doumler, *"C++ in the Audio Industry"* talks and *"Want fast C++? Know your hardware!"* (CppCon 2016).
