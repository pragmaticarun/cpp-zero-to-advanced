    Lesson 2.1: Control flow: if, switch, loops, and range-for¶

    C++20 · about 9 minutes

    Why this matters¶

    Imagine scanning a buffer of audio samples looking for the first one that clips. You need to loop, test each value, and stop early. That's control flow, and C++ has a few modern touches — like declaring a variable right inside an if — that make such code tighter and safer. Let's go through them quickly.

    if and the if-with-initializer¶

    You've seen if (cond) { ... } else { ... }. Since C++17 you can put a declaration inside the if:

    if (auto it = settings.find("volume"); it != settings.end()) {
    use(it->second);
}   // `it` is out of scope here: it can't be misused later

    The variable lives only as long as the if/else. Small scopes are a great habit: fewer names in play, fewer chances to use a stale one.

    switch¶

    switch works on integers and enums. Each case falls through to the next unless you break. Accidental fallthrough is a classic bug, so compilers warn (-Wimplicit-fallthrough). When you mean it, say so with [[fallthrough]];.

    Loops¶

    for (int i = 0; i < n; ++i) { ... }   // classic counted loop
while (cond) { ... }                  // test first
do { ... } while (cond);              // run at least once
for (const auto& x : container) { ... }   // range-based for (C++11)

    Range-based for is the default for "do something with each element". Use const auto& to avoid copying each element; use auto& if you want to modify them.

    C++20 added an initializer to range-for too: for (auto v = make(); auto x : v).

    Here's everything together, finding the first clipped sample:

    examples/week02/lesson01.cpp
    #include <iostream>
#include <vector>

enum class Level { quiet, normal, loud, clipping };

Level classify(float s) {
    const float a = s < 0 ? -s : s;   // conditional operator
    if (a >= 1.0f) return Level::clipping;
    if (a > 0.7f) return Level::loud;
    if (a > 0.1f) return Level::normal;
    return Level::quiet;
}

int main() {
    std::vector<float> samples{0.05f, 0.4f, -0.8f, 1.2f, 0.3f};

    int index = 0;
    for (const auto& s : samples) {
        if (const Level l = classify(s); l == Level::clipping) {   // if with initializer
            std::cout << "first clip at index " << index << '\n';
            break;
        }
        ++index;
    }

    for (auto& s : samples) s *= 0.5f;   // auto& modifies the elements

    for (std::size_t i = 0; i < samples.size(); ++i) {
        switch (classify(samples[i])) {
        case Level::clipping:
            std::cout << "C";
            [[fallthrough]];          // deliberate: clipping is also "loud"
        case Level::loud:   std::cout << "L "; break;
        case Level::normal: std::cout << "n "; break;
        case Level::quiet:  std::cout << ". "; break;
        }
    }
    std::cout << '\n';
}

    Output:

    first clip at index 3
. n n n n

    A common mistake: modifying a copy¶

    for (auto s : samples) s *= 0.5f;   // WRONG: halves a copy; samples unchanged
for (auto& s : samples) s *= 0.5f;  // right

    Pro tip

    Before writing a loop, ask: "is there an algorithm for this?" Finding the first matching element is std::ranges::find_if. We'll do a full tour of algorithms in Week 11 — loops are still fine for now.

    Key takeaways¶

    Key takeaways

    • Use if (init; cond) to keep helper variables scoped to the if.
    • switch cases fall through without break; mark intentional fallthrough with [[fallthrough]].
    • Range-for with const auto& reads without copying; auto& modifies in place.

    Quiz¶

    Q1. What's wrong with for (auto x : v) x = 0;?

    Show answer

    x is a copy of each element, so the vector is unchanged. Use auto& x.

    Q2. Where is it visible in if (auto it = m.find(k); it != m.end()) {...} else {...}?

    Show answer

    In the condition, the if body and the else body, but not after the whole statement.

    Q3. Why does the compiler warn about a case without break?

    Show answer

    Implicit fallthrough is a common bug. [[fallthrough]]; documents that it's intentional and silences the warning.
